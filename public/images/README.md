# Фотографии Zerkalo

Используйте только разрешённые к публикации кадры из [галереи Zerkalo в 2ГИС](https://2gis.ru/krasnoyarsk/gallery/firm/70000001088827266).

- `public/images/hero-02.webp` — вторая фотография из галереи 2ГИС, в формате WebP.
- `public/images/works/hair/` — фотографии стрижек.
- `public/images/works/nails/` — фотографии маникюра.

Галереи подхватывают файлы WebP, JPG, PNG и AVIF при сборке. Имена вроде `01.webp`, `02.webp` определяют порядок кадров. Добавьте файлы в репозиторий и пересоберите сайт. Если файлы ещё не добавлены, первый экран показывает декоративную графику, а раздел «Наши работы» ведёт в галерею студии в 2ГИС.
