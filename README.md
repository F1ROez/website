# Салоны Красноярска

## Запуск

После клонирования и установки Node.js 22 или новее:

```sh
npm install && npm run dev
```

Галерея http://localhost:3000

Страницы: /like-me/, /ambassador/, /rubleva/, /zerkala/, /four-suns/, /yestwobeauty/, /karina-meyskaya/, /four-seasons/, /t-studio/, /zerkalo/.

`npm run build` создаёт статический экспорт в out. `npm run typecheck` проверяет типы.

## Редактирование

В data/salons.ts находятся названия, основные адреса, ID карточек 2ГИС, цены и ссылки связи. В components/SalonPage.tsx — структура страниц, в app/globals.css — десять визуальных вариантов. Изображения находятся в public/images.

## Статус

Реализованы десять демонстрационных страниц и галерея на Next.js, TypeScript, Tailwind, Motion и Lucide. Сборка проходит. Публичные данные перенесены из исследования от 6 ноября 2026, требуют повторного подтверждения перед коммерческим запуском.

Ограничения текущей версии: интерактивные карты не подключены, использован честный резервный блок с карточкой 2ГИС. Дополнительные филиалы и переключатели ещё не реализованы. Like Me использует подтверждённую почту для связи вместо неподтверждённой записи. Внешние ссылки ещё не прошли повторную полную проверку. Мобильная версия предусмотрена CSS, но визуальный браузерный аудит и скриншоты ещё не выполнены. Отдельный экспорт каждого сайта требует выделения нужной конфигурации из общего проекта. Миниатюры галереи являются композициями с изображением и названием, а не скриншотами.

Фотографии Unsplash используются как явно обозначенные демонстрационные изображения. Они не являются портфолио или фотографиями помещений салонов. Исходные идентификаторы изображений перечислены в IMAGE-SOURCES.md. Для запуска от имени бизнеса нужны согласование содержимого и проверка прав на используемые материалы.
