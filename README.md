# Салоны Красноярска

Галерея из десяти демонстрационных сайтов на Next.js, React, TypeScript, Tailwind CSS, Motion и Lucide. [Открыть онлайн](https://krasnoyarsk-salon-collection.caringwoodpecker.chatgpt.site/). Для онлайн-версии нужен доступ владельца в ChatGPT.

## Запуск

Нужен Node.js 22 или новее. В папке репозитория выполните:

```sh
npm ci && npm run dev
```

Откройте http://localhost:3000/. При первом запуске нужен интернет для подготовки фотографий. После подготовки страницы загружают фото с собственного домена. Команда `npm run build` экспортирует сайт в `out/`. Для размещения отдайте эту папку статическому хостингу. Команда `npm run typecheck` проверяет типы.

```sh

```

```powershell

npm run build

```

## Как редактировать

- `data/salons.ts` — названия, услуги, подтверждённые цены, основные контакты и способ записи.
- `data/locations.ts` — адреса, телефоны, карточки, координаты и оценки филиалов. При выборе филиала меняются адрес, оценка и число оценок в 2ГИС, карта и ссылка на запись, если для филиала подтверждена отдельная форма. Данные об оценках хранятся в `ratings` и обновляются по карточкам 2ГИС.
- `widgetFor` в `data/locations.ts` собирает ссылку на [виджет организации 2ГИС](https://widgets.2gis.com/) по ID карточки и координатам выбранного филиала. Ссылка на карте открывает карточку этого филиала.
- `data/editorials.ts` — тексты страниц. `data/service-catalogs.ts` — разделы услуг, включая «Лабораторию стиля», и опубликованные сведения о специалистах.
- `data/photo-sources.json` и [IMAGE-SOURCES.md](IMAGE-SOURCES.md) — исходные фотографии, подписи и происхождение. Перед запуском и сборкой `scripts/prepare-photos.mjs` подготавливает локальные WebP. Для собственного домена задайте `SITE_URL` при сборке.
- `app/globals.css`, `app/salon.css` — базовые стили и индивидуальное оформление.

## Проверенные данные и ограничения

Данные проверялись 6 ноября 2026 года. На странице «4 сезона» указан велнес-центр на проспекте Мира, 52а. Институт красоты Babor на Мира, 105 — отдельная площадка того же юридического лица, поэтому он исключён из выбора адресов. Источники — [контакты «4 сезона»](https://4-seasons.ru/contacts/) и [«Лаборатория стиля»](https://4-seasons.ru/services/laboratoriya-stilya/).

У каждого из трёх филиалов YEStwoBEAUTY и у трёх филиалов Like Me проверена собственная форма YCLIENTS. Для Like Me на Октябрьской используется телефон сети, так как отдельная форма не открылась. У «Амбассадора» открывается опубликованная в 2ГИС форма YCLIENTS, а у T-Студио — форма Яндекс Записи с официальной страницы студии. Проверка не включала создание записей и проверку доступности конкретного времени.

Для услуг без подтверждённого тарифа выводится «Стоимость уточняйте». Точные цены, расписание отдельных мастеров и полный список сотрудников доступны не для всех салонов. На страницах используются материалы конкретных салонов и иллюстрации Unsplash там, где подходящих материалов салона пока нет. Сведения об услугах и специалистах опубликованы внутри страниц. Галереи чужих работ не копировались. На страницах пока используются дизайнерские миниатюры галереи. Перед публикацией от имени конкретного салона согласуйте фотографии и разрешите индексацию в metadata.
