# Салоны Красноярска

Галерея из десяти демонстрационных сайтов на Next.js, React, TypeScript, Tailwind CSS, Motion и Lucide. [Открыть онлайн](https://krasnoyarsk-salon-collection.caringwoodpecker.chatgpt.site/). Для онлайн-версии нужен доступ владельца в ChatGPT.

## Запуск

Нужен Node.js 22 или новее. В папке репозитория выполните:

```sh
npm ci && npm run dev
```

Откройте http://localhost:3000/. Команда `npm run build` экспортирует сайт в `out/`. Для размещения отдайте эту папку статическому хостингу. Команда `npm run typecheck` проверяет типы.

| --- | --- | --- |
| Like Me | [/like-me/](http://localhost:3000/like-me/) | YCLIENTS, телефон |
| Амбассадор | [/ambassador/](http://localhost:3000/ambassador/) | Телефон |
| Рублёва | [/rubleva/](http://localhost:3000/rubleva/) | Телефон |
| Зеркала | [/zerkala/](http://localhost:3000/zerkala/) | Telegram |
| Четыре Солнца | [/four-suns/](http://localhost:3000/four-suns/) | YCLIENTS, телефон |
| YEStwoBEAUTY | [/yestwobeauty/](http://localhost:3000/yestwobeauty/) | YCLIENTS, телефон |
| Карина Мейская | [/karina-meyskaya/](http://localhost:3000/karina-meyskaya/) | DIKIDI, Telegram |
| 4 сезона | [/four-seasons/](http://localhost:3000/four-seasons/) | Телефон выбранного адреса |

Для отдельного сайта укажите slug без косых черт. Его главная страница будет доступна по корневому адресу, галерея не включается.

```sh
SALON_SLUG=zerkalo npm run build
```

PowerShell:

```powershell
$env:SALON_SLUG = "zerkalo"
npm run build
Remove-Item Env:SALON_SLUG
```

## Как редактировать

- `data/salons.ts` — названия, услуги, подтверждённые цены, основные контакты и способ записи.
- `data/locations.ts` — адреса, телефоны, карточки, координаты и оценки филиалов. При выборе филиала меняются адрес, оценка и число оценок в 2ГИС, карта, маршрут и номер, если он подтверждён. Данные об оценках хранятся в `ratings` и обновляются по карточкам 2ГИС.
- `widgetFor` в `data/locations.ts` собирает ссылку на [виджет организации 2ГИС](https://widgets.2gis.com/) по ID карточки и координатам выбранного филиала. Ссылка на карте открывает карточку этого филиала.
- `data/editorials.ts` — тексты и ссылки на опубликованные работы или команды там, где они найдены.
- `data/images.ts` и [IMAGE-SOURCES.md](IMAGE-SOURCES.md) — демонстрационные фотографии и происхождение.
- `app/globals.css`, `app/salon.css` — базовые стили и индивидуальное оформление.

## Проверенные данные и ограничения

Данные проверялись 6 ноября 2026 года. Основные карточки 2ГИС находятся по ID из конфигурации, например [Like Me](https://2gis.ru/krasnoyarsk/firm/70000001042614977), [YEStwoBEAUTY](https://2gis.ru/krasnoyarsk/firm/70000001032935617) и [Babor](https://2gis.ru/krasnoyarsk/firm/985690699613400). Актуальные три филиала YEStwoBEAUTY сверены с [сайтом сети](https://yes2beauty.ru/) и списком в YCLIENTS. Старая копия каталога упоминает Ленина, 25, этот адрес отсутствует в текущих контактах и записи. Babor отмечен своим названием и телефоном, как отдельная площадка на [странице контактов «4 сезона»](https://4-seasons.ru/contacts/).

Списки филиалов Like Me и YEStwoBEAUTY открываются в YCLIENTS. Доступность конкретных слотов и завершение записи не проверялись. У T-Студио форма YCLIENTS показала ошибку сервера, поэтому используется Telegram из 2ГИС. Для остальных прямые кнопки ведут в опубликованный канал салона. Данные клиентов проект не собирает.

Для услуг без подтверждённого тарифа выводится «Стоимость уточняйте». Точные цены, расписание отдельных мастеров и полный список сотрудников доступны не для всех салонов. Фотографии на страницах демонстрационные. Ссылки на официальные работы или команды указаны отдельно, где они были подтверждены. На страницах пока используются дизайнерские миниатюры галереи. Перед публикацией от имени конкретного салона можно заменить демонстрационные фотографии его согласованными материалами и разрешить индексацию в metadata.
